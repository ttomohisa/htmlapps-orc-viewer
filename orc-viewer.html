使い方と注意事項
基本操作
  1. .orcファイルを1つまたは複数選択・ドロップします。
  2. ファイル情報で行数、圧縮方式、ストライプ、列統計、メタデータを確認します。
  3. スキーマをTree / Rawで確認し、データをTable / Recordで表示します。
  4. 現在ページの読み込み完了後にCSVをコピー・保存できます。読み込み中やエラー時は出力できません。
「列」で列名を検索し、完了で表示列を適用します。キャンセル・Escで変更を破棄します。Tableの列名ボタンはクリックまたはEnter / Spaceで現在ページを昇順・降順・元の順に並べ替えます。DECIMAL列は精度を保って数値順に並べ替えます。
ルートがstruct以外のORCは、値をroot列として表示・CSV出力します。時刻はミリ秒単位の表示で、書き込み側のタイムゾーンの解釈に既知の制限があります。元の時刻・精度が必要な場合は専用ツールで確認してください。
プライバシー
読み込んだファイルはブラウザー内だけで処理します。このアプリから外部サーバーへ送信しません。
注意事項
  • 現在のバージョンはApache ORCファイルを閲覧する読み取り専用ツールです。
  • NONE / ZLIB / SNAPPY / LZ4を読み込みます。ZSTDはブラウザーが対応する場合に利用し、LZOは未対応です。
  • 閲覧専用です。元のORCファイルを書き換えません。
  • CSV出力は現在ページのみです。読み込み失敗時は1ページの行数を変更するか、別タブに移動して戻ると再試行できます。
配布用HTMLは実行時の外部通信を必要とせず、ローカルファイルとして直接開けます。
